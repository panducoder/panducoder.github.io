Workflow Mirror

Record a workflow as live, clickable copies of each page — lighter than video, richer than screenshots.

2026Tools & appsSolo build
Try it · How it works
How it worksClick or tap the steps
01The problem

Screenshots are flat, screen recordings go stale and session replays are fragile and costly. Teams need lightweight, interactive walkthroughs of real apps.

02How it works
  1. Capture. A Chrome extension captures each page's full DOM, the computed styles that differ, every asset inlined, and the element you clicked.
  2. Clean. The server strips scripts and handlers, converts images to WebP and de-duplicates assets by hash.
  3. Link the steps. The clicked element is highlighted, navigation is disabled, self-contained widgets stay interactive.
  4. Replay. A viewer stacks the steps as sandboxed frames with scroll-snap and lazy loading.
  5. Share. REST API, expiring share links with view limits, signed webhooks.
03My role

Built through eight phases with tests, and wrote up what broke — a CSS escaping bug and an asset-collection bottleneck.

04Result

Working prototype; demoed to a solutions team.
