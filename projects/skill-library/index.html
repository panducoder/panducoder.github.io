01The problem

If a workflow lives only in my head, it varies every time. Written as a skill, an AI runs it the same way every time.

02How it works
  1. One file per skill. Each skill is a SKILL.md with a trigger description and a procedure.
  2. Workflow skills. Capture, follow-ups, inbox, end-of-day sweep and reviews, routed into my task and note tools.
  3. Creation skills. Explainers, decks, PRDs, evals, posts and film prompts.
  4. Research skills. Market and company research procedures.
