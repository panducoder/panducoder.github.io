01The problem

When training, assessment, practice and field evidence live in separate tools, nobody can say ‘this person did this training, and here is what changed’ — so the value of training is hard to prove at renewal.

02How it works
  1. A shared language. A competency registry gives every product the same names for the same skills.
  2. An evidence contract. Learning, assessment, AI practice, call analysis, manager coaching and buyer feedback all report evidence in one xAPI-style format, through adapters.
  3. A ladder of proof. Each seller sits on a five-rung ladder from ‘knows it’ to ‘does it consistently, with effect’. Each kind of evidence can only lift you so far.
  4. Profiles that decompose. An interpretation service builds a profile per person and an index per team — and any number can be broken back into the evidence behind it.
  5. In the workflow. An API, a consultant view and an MCP server put the method where sellers already work.
