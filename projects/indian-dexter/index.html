Indian Dexter: data for a markets agent

Before building a financial-analysis agent for Indian markets, I tested which free data sources actually work.

01The problem

US financial agents sit on clean APIs. In India the data is scattered across exchanges, regulators and scrapers, and most blog posts about it are out of date.

02How it works
  1. Map the landscape. Sixteen data categories, from financial statements to insider trades.
  2. Stress test. Test every source against a small-cap company — if it works there, it works almost anywhere.
  3. Score. Works, partial or broken, and whether auth or a browser is needed.
  4. Recommend a stack. The combination that covers the most with the least fragility.
03My role

The research, Python test scripts and three reports.

04Result

Research complete; the recommended stack is ready for an agent.
