Koi: a voice companion that speaks Hinglish

Tap and talk to an AI companion in natural Hinglish, with memory of past conversations — built for sub-second replies.

01The problem

Voice AI is built for English. Most Indians speak a mix of Hindi and English, and an assistant that can't keep up with that — or forgets you every time — isn't a companion.

02How it works
  1. Real-time audio. A React Native app streams audio over WebRTC through LiveKit.
  2. Hear. A Python agent transcribes with an Indian speech model built for code-mixed speech.
  3. Remember and think. An Indian LLM with a persona prompt, plus semantic memory in a vector database.
  4. Speak. An Indian text-to-speech voice replies; the target is first audio in under a second.
  5. Backend. Supabase for auth, data and edge functions.
03Decisions & trade-offs

OverGlobal English-first models
