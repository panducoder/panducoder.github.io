01The problem

Posting useful AI-product content every day takes hours. Naive automation posts off-voice or wrong — and fails silently.

02How it works
  1. Astra writes. Researches, writes and reviews each piece in a versioned folder.
  2. Ready queue. Only reviewed versions enter the queue, with exact versions and delivery receipts.
  3. Keeni acts. Performs browser actions, writes replies, records stats and recovers from failures.
  4. Operations layer. Claims, events, incidents, metrics and runbooks — like a small SRE team.
  5. Dashboard. Daily verified activity, the publication ledger, the queue and failures with corrective actions.
03My role

The agent roles, the operations layer, the dashboard and the explainer pipelines.

04Result

Running; trial runs and published explainers.
