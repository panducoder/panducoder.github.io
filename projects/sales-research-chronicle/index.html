01The problem

Revenue leaders hear ‘research shows…’ with nothing behind it. Peer-reviewed work and vendor studies get mixed together.

02How it works
  1. Collect. Studies from publisher, university and journal pages.
  2. Separate the tracks. Peer-reviewed and vendor work kept visibly apart; working papers flagged.
  3. Cluster. Six currents, each with a finding line the evidence supports.
  4. Generate. A Python script builds the Markdown and the filterable page.
  5. So what. Seven conclusions, each tied to a named study, plus method and caveats.
03My role

The research, the build script and the page.

04Result

Finished and shareable.
