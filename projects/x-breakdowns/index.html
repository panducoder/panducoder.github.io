Five-agent X breakdown pipeline

Scout a viral post, research the story behind it, write the breakdown, pass a quality gate, then publish.

2026Agents & automationSolo build
How it worksClick or tap the steps
01The problem

Good quote-posts explain the hidden ‘why’ behind a viral post. That takes hours of research per post.

02How it works
  1. Scout. Pick a post from a ranked shortlist, or use a given URL.
  2. Research. Decompose the post and gather sourced numbers, incentives and a twist.
  3. Write. Draft the quote-post, alternate hooks and an infographic card.
  4. Gate. An editor agent scores engagement and accuracy, with up to three rewrites until it passes.
  5. Publish. Posted by computer use; a separate agent handles short replies.
03My role

The agent specs, the infographic renderer and the run logs.

04Result

Ran daily for a week; about 14 posts, several correctly stopped by the gate.
